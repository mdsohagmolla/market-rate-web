# BazarDor — বাজার দর

A simple web application to check daily prices of essential products in Bangladesh.

# 🚀Features

- View product prices

- Track price increases and decreases

- Browse all products

- Responsive design

# 🛠️Technologies

- Next.js

- React

- TypeScript

- Tailwind CSS
